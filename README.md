# EURASIA — интернет-магазин профессиональной косметики

Статический сайт: HTML, CSS, JS без сборки. Каталог, карточка товара, бренды, корзина и оформление заказа собраны по макету из Figma и приведены в соответствие с фирменным гайдлайном (логотип, палитра, название EURASIA).

Корзина, избранное и промокод хранятся в `localStorage` браузера — бэкенда нет, оформление заказа ничего никуда не отправляет.

## Запуск локально

Сайт можно открыть напрямую (`index.html`), либо поднять локальный сервер:

```bash
python3 -m http.server 5173
```

и открыть http://localhost:5173

## Структура

- `index.html`, `catalog.html`, `product.html`, `brand.html`, `brands.html`, `cart.html`, `checkout.html` — страницы
- `css/style.css` — стили
- `js/data.js` — данные каталога (бренды, категории, товары)
- `js/app.js` — вся логика: рендер карточек, корзина, избранное, фильтры, формы
- `assets/` — изображения и иконки
